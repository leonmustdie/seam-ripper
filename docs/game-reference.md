# Game reference

What is inside the games: what the scripts do, how the files are laid out,
and what was found in the prototype builds. These pages are about Naughty Bear
and Panic in Paradise, not about the tool. For how to read and edit a script
with Seam Ripper see the [Seam Ripper reference](tool-reference.md), and for
finished mods built on these findings see the [Examples](examples/index.md).
